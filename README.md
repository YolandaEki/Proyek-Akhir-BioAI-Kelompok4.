# Optimasi Klasifikasi Kultivar Anggur dan Evaluasi Struktur Pengelompokan Berdasarkan Karakteristik Kimia Wine Menggunakan Machine Learning

Proyek akhir mata kuliah **Data Science & Artificial Intelligence untuk Biologi** yang berfokus pada pemodelan *Supervised Learning* (klasifikasi multi-kelas) dan *Unsupervised Learning* (reduksi dimensi PCA serta klasterisasi K-Means) pada dataset `load_wine`.

## Luaran Proyek

2. Jupyter Notebook (`.ipynb`) analisis & implementasi AI serta notebook demonstrasi interaktif

4. Presentasi (PPT/PDF)
5. Demonstrasi project (notebook interaktif / antarmuka Gradio)

1. Buka file `.ipynb` di **Google Colab** atau **Jupyter Notebook**.
2. Jalankan sel satu per satu atau klik **Runtime → Run all**.
3. Untuk demonstrasi interaktif, jalankan sel Gradio lalu buka tautan `https://xxxx.gradio.live` yang muncul.
